# Apricot Neo — Agent Skill

## Documentation Discipline

After every execution:

1. Inspect the relevant `/docs` files before making architectural decisions.
2. Preserve the existing roadmap structure, terminology, and tone.
3. Update `/docs` to reflect implemented work and current status.
4. Write a concise summary of what was implemented.
5. Update the relevant phase/status when work is actually complete.
6. Never mark planned or partial work as complete.
7. Keep documentation changes proportional to the task.

## Decision Discipline

When unsure:

1. Inspect the repository and existing documentation first.
2. Check `docs/DECISIONS.md`.
3. Do not invent architectural decisions.
4. Ask the developer if ambiguity remains.

## Scope Discipline

* Implement only the requested task.
* Do not silently advance to the next phase.
* Do not implement future roadmap items unless explicitly requested.
* Prefer minimal, maintainable changes over unnecessary abstractions.
* Run relevant tests and quality checks before reporting completion.

## Completion Report

End every execution with:

* Implemented
* Tests / validation
* Documentation updated
* Remaining issues
* Next recommended task
